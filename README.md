# 🛠️ ساخت شبیه‌سازهای تعاملی تجهیزات (Interactive Hardware Simulators)

مجموعه‌ای از ابزارهای تحت وب، سبک و بدون وابستگی برای ساخت **راهنمای تعاملی بردهای الکترونیکی**، تجهیزات امنیتی، صنعتی و آموزشی. کاربر با بردن موس روی هر بخش از قطعه، توضیح کوتاه و با کلیک، توضیحات کامل و مشخصات فنی آن بخش را می‌بیند.

> ساخته‌شده و نگهداری‌شده توسط **[اینتل‌سافت](https://intellsoft.ir)** — توسعه‌دهندهٔ ابزارهای آنلاین تخصصی و نرم‌افزارهای امنیتی.

---

## 📌 چرا شبیه‌ساز تعاملی؟

- **آموزش سریع‌تر**: کاربر بدون خواندن دفترچهٔ ۴۰ صفحه‌ای، در ۳۰ ثانیه با قطعه آشنا می‌شود.
- **کاهش پشتیبانی**: سوالات تکراری «این پیچ چیه؟» یا «تامپر کجاست؟» حذف می‌شود.
- **سئو**: محتوای متنی هر بخش (مشخصات، کاربرد، نکات نصب) به‌صورت HTML رندر می‌شود و برای موتورهای جستجو قابل ایندکس است.
- **قابل استفاده در فروشگاه**: به‌عنوان صفحهٔ محصول یا راهنمای نصب در کنار محصول قرار می‌گیرد.
- **بدون وابستگی**: فقط HTML + CSS + JavaScript خالص (Vanilla). نه React، نه کتابخانهٔ سنگین.

---

## 🧩 اجزای اصلی یک شبیه‌ساز تعاملی

| جزء | توضیح |
|---|---|
| **SVG قطعه** | نقشهٔ برد یا بدنهٔ محصول به‌صورت SVG برداری (مقیاس‌پذیر و سبک). |
| **Hotspot** | نواحی قابل کلیک با `class="zp2-hotspot"` و `data-part="key"`. |
| **پنل توضیحات** | یک `<aside>` که محتوای HTML مربوط به هر بخش را نمایش می‌دهد. |
| **Tooltip** | توضیح کوتاه شناور روی موس/لمس. |
| **دیکشنری داده** | آبجکت `PARTS` شامل `title`، `short`، `body` و `tag` برای هر بخش. |
| **دسترس‌پذیری** | `tabindex`، `role="button"`، پشتیبانی از `Enter/Space` و لمس. |

## 🚀 مراحل ساخت گام‌به‌گام

### ۱. آماده‌سازی نقشهٔ قطعه
عکس محصول را در Illustrator/Figma ترسیم مجدد کنید یا از SVG آماده استفاده کنید. خروجی را با `viewBox` مناسب ذخیره کنید.

### ۲. تعریف نواحی تعاملی (Hotspot)
هر بخش را در یک `<g>` با ویژگی‌های زیر بگذارید:

```html
<g class="zp2-hotspot" data-part="pir" tabindex="0" role="button" aria-label="سنسور PIR">
  <!-- شکل ظاهری -->
  <circle cx="375" cy="230" r="75" fill="#555"/>
  <!-- لایهٔ هایلایت -->
  <circle class="zp2-hl" cx="375" cy="230" r="75"/>
</g>
